# Drawer 概述

### 简介

Drawer 抽屉是一种从屏幕边缘滑出的浮层面板组件。当需要在不离开当前页面的情况下展示额外内容（如表单、详情信息、操作选项等）时，抽屉可以提供流畅的交互体验，避免页面跳转带来的上下文切换。

![AtomUI Drawer组件](./images/extra-and-footer.webp)

### 主要功能

* 基础侧边抽屉，通过 `IsOpen` 属性控制开关状态
* 支持四个方向弹出（左/上/右/下），通过 `Placement` 属性配置
* 可选遮罩层显示，支持点击遮罩关闭抽屉
* 自定义头部 Extra 区域和底部 Footer 区域
* 容器内局部渲染模式，通过 `OpenOn` 属性指定目标容器
* 支持多层级嵌套抽屉
* 内置预设尺寸（默认 378px / 大尺寸 736px），也可通过 `DialogSize` 自定义
* 开启/关闭动画效果
