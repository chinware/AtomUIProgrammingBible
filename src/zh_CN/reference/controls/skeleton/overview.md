# Skeleton 概述

### 简介

Skeleton 是一个占位符组件，在数据加载完成前为用户提供一个内容的预览骨架，避免页面出现长时间的空白，提升用户体验。

![AtomUI Skeleton组件](./images/basic.png)

### 主要功能

* 支持通过 `IsLoading` 控制占位符的显示与隐藏
* 支持头像、标题、段落等多种占位元素的组合
* 支持自定义段落行数、行宽、头像形状与尺寸
* 支持包裹动态内容，在加载完成后自动展示真实内容
* 提供 SkeletonButton、SkeletonAvatar、SkeletonInput、SkeletonImage、SkeletonNode 等子组件，满足多样化的占位场景
* 支持圆角（`IsRound`）样式
