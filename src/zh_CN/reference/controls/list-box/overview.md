# ListBox 列表框

## 简介

列表框组件用于在一组选项中展示和选择数据。AtomUI 的 ListBox 组件继承自 Avalonia 原生 ListBox，在此基础上扩展了悬停/选中背景色自定义、选中指示器、无边框模式、空状态指示器、条目过滤与高亮等特性，能够满足各类列表展示与交互场景的需求。

![AtomUI ListBox组件](./images/basic.webp)

## 何时使用

- 需要从一组选项中展示数据列表时
- 需要支持单选或多选交互时
- 需要对列表条目进行过滤筛选时

## 主要特性

- **悬停与选中样式** — 支持自定义条目悬停背景色（ItemHoverBg）和选中背景色（ItemSelectedBg），灵活适配不同 UI 风格
- **选中指示器** — 通过 IsShowSelectedIndicator 开启选中指示器，并可自定义指示器图标模板
- **无边框模式** — 通过 IsBorderless 属性切换为无边框样式，融入更多布局场景
- **空状态展示** — 内置空状态指示器，当列表无数据时自动展示，支持自定义空状态内容和模板
- **条目过滤与高亮** — 支持通过 ItemFilter 进行条目过滤，并自动高亮匹配文本，提供实时过滤结果计数
- **尺寸规格** — 通过 SizeType 属性切换不同的尺寸规格
- **过渡动画** — 内置平滑的过渡动画效果
