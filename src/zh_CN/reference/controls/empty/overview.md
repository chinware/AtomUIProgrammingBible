# Empty 空状态

## 简介

空状态组件用于在没有数据时提供友好的占位提示，告知用户当前区域暂无内容。支持预设图片和自定义图片，可配合描述文字引导用户进行下一步操作。

![AtomUI Empty 组件](./images/basic.png)

## 何时使用

- 列表、表格、卡片等容器在没有数据时，用于展示空状态占位
- 初始化页面尚无内容时，给予用户视觉提示
- 搜索或筛选无结果时，提示用户调整条件

## 主要特性

- **预设图片** — 内置 Default 和 Simple 两种风格的预设空状态图片
- **尺寸适配** — 支持 Small、Middle、Large 三种尺寸，适应不同场景
- **自定义图片** — 通过 ImagePath 或 ImageSource 加载自定义图片
- **描述信息** — 支持显示描述文字，可控制显示或隐藏
