# Rate 概述

### 简介

Rate 评分组件用于对事物进行快速的评级操作，支持全星与半星两种步进粒度。用户可以通过点击或键盘操作完成打分，同时支持自定义字符、提示文字和只读模式等多种场景。

![AtomUI Rate组件](./images/half-star.webp)

### 何时使用

- 对事物进行快速且直观的评级，例如商品评价、满意度调查等。
- 需要展示已有评分结果（只读模式）。

### 主要功能

- 基础步进支持全星、半星
- 支持清除已选评分（`IsAllowClear`）
- 支持只读展示与设定默认值
- 支持自定义字符（图标、字母、汉字等）
- 支持鼠标悬停提示文字
- 支持键盘操作
- 支持三种尺寸（`SizeType`）
