# Result 概述

### 简介

在很多业务场景中，当用户完成一个操作流程后，需要一个醒目的结果反馈页面来告知操作状态。`Result` 组件正是为此而生，它提供了一套完整的结果展示方案，支持成功、失败、警告、提示等多种状态。

![AtomUI Result组件](./images/success.png)

### 主要功能

* 内置 `Success`、`Info`、`Warning`、`Error` 四种常见结果状态
* 内置 HTTP `403`、`404`、`500` 错误码展示风格
* 支持自定义图标，满足个性化需求
* 支持自定义标题、副标题、额外操作区域及主体内容
* 继承自 `ContentControl`，可在内容区域放置任意自定义布局

### 何时使用

* 当需要向用户展示操作结果的状态时
* 当需要展示带有详细说明和后续操作的反馈页面时
* 当需要展示 HTTP 错误页面（如 403、404、500）时
