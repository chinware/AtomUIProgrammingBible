# 快速入门

### 基础配置条件

* Nuget安装Avalonia
* Nuget安装AtomUI

### 基础用法

`Watermark` 属性类似于HTML中的Placeholder，起到一种占位符的作用。

![AtomUI DatePicker组件](./images/basic.webp)

```axaml
<atom:DatePicker Watermark="Select date"/>
```

### 日期范围选择

![AtomUI DatePicker组件](./images/range.webp)

```axaml
<atom:DatePicker Watermark="Select date"/>
```
