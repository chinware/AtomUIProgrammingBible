# Collapse 概述

### 简介

Collapse 折叠面板是一种可以将内容区域进行折叠/展开的容器组件。当页面内容较多且需要分组展示时，折叠面板可以有效地节省页面空间，让用户按需查看感兴趣的内容。

![AtomUI Collapse组件](./images/basic.webp)

### 主要功能

* 基础折叠面板，支持多个面板项同时展开或收起
* 手风琴模式（IsAccordion），同一时间仅展开一个面板
* 三种尺寸（Small / Middle / Large）适配不同场景
* 无边框样式（IsBorderless）与幽灵样式（IsGhostStyle）
* 嵌套折叠面板，支持多层级内容组织
* 展开图标位置可配置（Start / End）
* 触发区域可配置（Header 整行触发或仅 Icon 触发）
* 自定义表头与内容区域的内间距
