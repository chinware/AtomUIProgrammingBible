# Palette 调色板

## 简介

AtomUI 提供了一套基于 Ant Design 色彩体系的默认调色板，同时内置了功能丰富的 `ColorPicker` 颜色选择器组件。调色板涵盖了品牌色、功能色和中性色等完整色系，帮助开发者在应用中保持一致的视觉风格。`ColorPicker` 组件允许用户通过可视化面板选取颜色，支持多种颜色格式、透明度调节和预设色板等能力。

![AtomUI Palette 调色板](./images/palette.webp)

## 何时使用

- 需要用户从可视化面板中选取颜色时
- 表单中需要颜色输入字段时
- 需要提供预设调色板供用户快速选择时
- 主题定制、画布编辑等涉及颜色配置的场景

## 主要特性

- **多种颜色格式** — 支持 HEX、RGB、HSB 等格式，可通过 `Format` 属性切换
- **透明度支持** — 通过 `IsAlphaEnabled` 开启 Alpha 通道调节
- **预设色板** — 通过 `PaletteGroup` 提供一组预设颜色，方便用户快速选取
- **弹出触发方式** — 支持点击和悬停两种方式触发颜色选择面板
- **多种尺寸** — Large、Middle、Small 三种尺寸适配不同布局密度
- **清除功能** — 支持清除已选颜色，恢复为空状态
- **动画效果** — 内置过渡动画，可通过 `IsMotionEnabled` 控制
